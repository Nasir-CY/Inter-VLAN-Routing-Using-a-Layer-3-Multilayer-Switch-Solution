# Inter-VLAN-Routing-Using-a-Layer-3-Multilayer-Switch-Solution
#### This report documents a project on inter-VLAN routing implemented entirely on a single Layer 3 (multilayer) switch, using Switch Virtual Interfaces (SVIs) rather than an external router. This is a third method of inter-VLAN routing, alongside the two-physical-interface method and Router-on-a-Stick documented in earlier phases of the McNasir Systems network project, and represents the approach generally preferred in enterprise environments where the hardware is available.

## Advantages of Inter-VLAN Routing Using Layer 3 Switches
* **Extremely fast**
* **Hardware-based routing**
* **Supports thousands of VLANs**
* **No trunk bottleneck**
* **Ideal for enterprise networks**
* **High performance**

## Disadvantages of Inter-VLAN Routing Using Layer 3 Switches
* **More expensive**
* **Requires Layer 3 switch hardware**
* **Configuration is slightly more advanced**
